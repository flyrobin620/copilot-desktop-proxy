How tokens are counted

Total = uncached input + output + cache read + cache write. Claude Code context and tool definitions can add tokens even to a short prompt.

These are processed tokens, not account billing or remaining quota.

Local cumulative history

Only requests passing through this proxy are recorded. History is retained across restarts.

Direct Copilot app activity, other proxies and other computers are excluded. All clients using this local proxy contribute to its totals.

Stores token counts, timing and status locally. Prompts, responses and credentials are never saved in the usage database. Interrupted requests may have partial usage.
