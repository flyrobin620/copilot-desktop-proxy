# Repository operations

To install, update, or make a pulled version take effect, follow
[.agents/skills/copilot-proxy-update/SKILL.md](.agents/skills/copilot-proxy-update/SKILL.md):
it runs `scripts/install.ps1`, which performs every step and verification.
Human-facing instructions: [docs/UPDATE.md](docs/UPDATE.md).
For source development, see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md); run tests with
`python -B -X utf8 -m unittest discover -s tests -t . -q`.
